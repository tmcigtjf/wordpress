# WordPress主机推荐：不用备案也能一键建站，新手从0元虚拟主机到云服务器怎么选

搜"WordPress主机推荐"的人，卡点通常不在"哪个牌子好"，而在两个更具体的问题上：域名要不要备案，以及一台理论上"能跑"WordPress 的机器，实际撑不撑得住自己那堆插件。这两件事没想清楚，买多贵的都容易翻车，买太便宜的也会在第三个月开始变慢。

## WordPress 吃资源的姿势，和静态站完全不是一回事

一个纯静态 HTML 站，512MB 内存跑到天荒地老都没事。WordPress 不行：每次访问都要走 PHP 解释 + MySQL 查询，后台还挂着定时任务、自动更新、图片缩略图生成。你装的每一个插件都会往这个链条上加一道工序。

所以选配置时可以先给自己分个类：

- 纯个人博客、几十篇文章、访客不多：1核1G 够用，瓶颈是内存不是 CPU
- 装了缓存插件、SEO 插件、安全插件这一套"标配三件套"：1G 内存会开始紧张，2G 舒服很多
- 跑 WooCommerce 或者带会员系统：直接按 2核2G 起步考虑，别在 1G 上挣扎

WordPress 本身对硬盘要求不高，但数据库读写频繁，SSD 是底线。雨云目前在售的虚拟主机和云服务器都是 NVMe SSD 配 RAID 冗余，这一点不用担心。

## 先定机房，再定配置：备案这件事决定了你的选择范围

国内机房延迟低、稳定，代价是域名必须完成 ICP 备案，整个流程快的话几天，慢的话两三周。海外机房免备案，但延迟上去了。雨云虚拟主机可以选的三个区域，差距基本就在这儿：

| 区域 | 是否需备案 | 线路特点 | 教程里给出的参考延迟 |
| --- | --- | --- | --- |
| 江苏宿迁 | 需要 | 京东云 BGP，百 GB 级 DDoS 防御 | 约 25ms |
| 中国香港二区 | 免备案 | 三网直连 BGP，带宽相对小 | 约 88ms |
| 美国洛杉矶一区 | 免备案 | 国际大带宽 AS4837 | 约 173ms |

（延迟数字来自公开的建站教程测速，只作量级参考，实际路由会波动。）

选法很直白：面向国内读者、又愿意备案，宿迁是首选；不想折腾备案，香港是最省事的折中；如果你的站是资源下载、图片为主、对延迟不敏感，洛杉矶一区的大带宽更划算。

## EP 主机、宝塔主机、云服务器，这三种其实对应三种人

雨云的虚拟主机分两套面板，加上海外和国内机房，再加上独立的云服务器产品线，很多人第一次进控制台会看花眼。

**EP 主机（EasyPanel 面板）** 是最便宜的一档，带宽和存储独享，CPU 和内存共享，一个主机限制绑定 5 个域名，只支持单数据库 + PHP 环境的组合。装一个 WordPress 完全没问题，但它不适合你同时跑好几个站或者往里塞 Java、Python 服务。

**宝塔主机** 基于 LXD 容器，CPU、内存、带宽、硬盘都是独享的，能拿到完整权限的宝塔面板，不限站点数量、不限数据库和域名，支持 SSH / SFTP / MySQL 远程连接，预装 LNMP 环境。它对 WordPress 最友好的地方是：软件商店里有一键部署，主题插件随便折腾，环境出问题自己能救。代价是默认使用共享 IP，只能开放固定几个端口，需要独立 IP 可以额外附加。

**云服务器** 走 KVM 虚拟化，独立 IP、全端口自由，想装什么环境装什么。如果你打算在这个站上长期投入，或者需要跑邮件、Redis、Docker 这些东西，云服务器是唯一合理的选择。

一句话总结选择逻辑：只做一个 WordPress 站、预算紧张，从宝塔主机入手；同时维护多个站点且必须自己掌控环境，宝塔主机的性价比就出来了；要独立 IP 和完全自由，直接看云服务器。

## 从买到跑起来，实际就这几步

1. 注册账号并绑定微信领券，进控制台 → 云产品 → 虚拟主机，选好区域和面板类型下单
2. 等待自动创建，宝塔主机一般 1 到 5 分钟，创建完成后进控制面板，用弹出的账号密码登录宝塔
3. 域名可以是自己注册的，也可以用雨云提供的免费二级域名，解析指向主机
4. 宝塔面板里点"一键部署"找 WordPress，填域名、勾选自动创建数据库，提交后进浏览器完成安装向导，数据库地址填 `localhost`
5. 装完之后把缓存插件、SSL 证书配上，宝塔里可以直接申请 Let's Encrypt 免费证书

整个流程对没有运维经验的人来说大概半小时到一小时，卡住的地方通常不是 WordPress，而是域名解析还没生效。

## 几个一定会遇到的坑

**域名要在两个地方绑定。** 在宝塔里建完站、绑好域名之后，还得回雨云虚拟主机控制面板的域名管理里再绑一次，漏掉这一步的话，网站就是打不开，而且报错信息完全看不出是这个原因。

**数据库地址别填远程端口。** WordPress 安装时数据库主机填 `127.0.0.1`，端口 `3306`，不要照抄雨云面板上显示的远程 MySQL 端口号。用 Navicat 这类工具远程连的时候才需要那个端口。

**phpMyAdmin 的默认端口要改。** 共享 IP 下 888 端口通常不可用，链接里的端口得换成控制面板里实际分配的那个。

**别在宝塔里升级面板或者乱改端口。** 官方文档明确不建议升级，容器环境下升级宝塔容易把面板弄挂，真出问题了可以用雨云的"修复主机"功能救回来。

**共享 IP 意味着端口受限。** 如果你要在这台机器上跑邮件服务、或者需要非常规端口对外，附加独立 IP 是必须的，费用在每月几元这个量级。

## 谁适合，谁别买

适合的：个人博客、技术笔记、作品集、小型企业展示站、日访客在几千以内的内容站。雨云从 2018 年运营到现在，持有工信部相关资质，支付宝微信直接付款，控制台全中文，出了问题的沟通成本比海外主机低很多。

不太适合的：预期日访客上万、需要弹性扩容、要跑复杂业务系统或者邮件服务的项目。这类需求应该直接上云服务器，甚至考虑别家更高规格的产品线。低价套餐的 CPU 和内存配额是硬限制，资源打满之后网站会变慢甚至被暂停，这不是雨云独有的问题，而是这个价位段的通用规则。

## 几个常被问到的问题

**免费版能上正式站吗？** 技术上可以，1核512MB 跑一个纯文字博客足够。但它更适合当"练手环境"，5GB 硬盘放几十张图就满了，长期当主力站用会很快遇到存储瓶颈。

**香港和美国选哪个？** 面向国内读者就选香港，延迟差了将近一倍。除非你的流量主要来自海外，或者网站以文件下载为主，那就按带宽选洛杉矶。

**没有备案能用国内机房吗？** 不能。宿迁等国内机房都要求域名完成 ICP 备案，这条没有绕过去的办法，不想备案就走香港或美国。

**主机能升级吗？** 虚拟主机套餐支持随时升到更高配置，官方给的时间是一分钟内自动完成，数据不用自己搬迁。真到了需要独立 IP 和全端口的阶段，也可以换到云服务器。想先从便宜的开始试，选一台符合当下需求的配置就行，[👉 进控制台挑一台合适的方案](https://www.rainyun.com/MzA2MTc2_) 比反复对比参数表更快出结果。
